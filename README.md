# BMS5002 第二講學習站

傳染病的原理、偵測與診斷（Principle, Detection and Diagnosis of Infectious Diseases）

依據何明亮教授（香港城市大學生物醫學系）BMS5002 Lecture 2 投影片重建的本地學習網站。

## 如何開啟

請用 **Safari / Chrome / Edge** 打開 `index.html`（不要用「文本編輯」或 Word）。

樣式與互動腳本已全部內嵌在 `index.html` 裡，雙擊即可顯示完整排版。圖片仍放在同資料夾的 `images/` 中，請不要只複製單一個 HTML 檔。

**方法一：** 用瀏覽器直接打開 `index.html`。

**方法二（建議）：** 在本資料夾執行本機伺服器，可避免部分瀏覽器對本地檔案的限制。

```bash
cd "/Users/mason/Desktop/BMS5002-Lecture2-Learning"
python3 -m http.server 8877
```

然後在瀏覽器開啟：http://127.0.0.1:8877/

## 功能

- 繁體中文為主要說明語言；學術詞彙保留英文並附中文譯名
- 右上角可在「繁體／简体」之間切換
- 右上角「學習自評」：20 題隨堂測驗，交卷後顯示解析
- 講義中的圖表均截取自原 PDF；另有少量補充圖協助理解流程
